# HMS design system

The visual language is information-first clinical software. It uses a deep teal primary, warm neutral surfaces, semantic status colours, a single humanist system sans stack, 4/8px spacing, and tabular figures for clinical values and LKR amounts.

Both themes are token-driven (`--background`, `--surface`, `--ink`, `--muted`, `--primary`, semantic status tokens). Dark mode uses layered charcoal neutrals rather than black or neon. Focus rings always meet contrast requirements; buttons, dialogs, menus, and form controls retain keyboard focus treatment.

Data screens use compact rows, sticky table headers, inline filters, intentional empty states, and predictable shortcuts: `/` focuses global search and `N` opens the primary create workflow when the current user has permission. Patient-facing modules will pin the patient banner above clinical content.
